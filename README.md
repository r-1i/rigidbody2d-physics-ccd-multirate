# 2D Rigid Body Physics: CCD и Multi-rate симуляция
Упрощённый 2D rigid body physics движок на C++ с визуализацией на SDL2.
Проект выполнен в рамках практического задания «Блок Механика» (Моделирование
Физических Процессов, ИТМО). Реализованы и сравниваются два подхода к борьбе
с туннелированием быстрых объектов:
- **CCD (Continuous Collision Detection)** — аналитический поиск момента
  столкновения внутри временного шага (круг–круг: квадратное уравнение;
  круг–AABB: покомпонентный slab method).
- **Multi-rate simulation** — объекты разделены на группы с разной частотой
  обновления: обычные — 60 Гц, быстрые (снаряды) — 240 Гц (sub-stepping).
## Сборка
**Зависимости:**
- C++20-компилятор (MSVC `cl.exe` на Windows)
- [CMake](https://cmake.org/) ≥ 3.21 и генератор Ninja
- [vcpkg](https://vcpkg.io/) (переменная окружения `VCPKG_ROOT`) — подтягивает
  зависимости `sdl2` и `sdl2-gfx` (см. `vcpkg.json`)
**Windows (пресеты):**
```powershell
cmake --preset x64-release
cmake --build --preset x64-release
```
Также доступны пресеты `x64-debug`, `x86-debug`, `x86-release`.
Для Linux/macOS есть пресеты `linux-debug` и `macos-debug` (зависимости SDL2
нужно установить через системный пакетный менеджер или vcpkg).
Исполняемый файл: `out/build/x64-release/rigidbody2d-ccd-multirate.exe`
## Управление
| Клавиша | Действие |
|---|---|
| `M` | Следующая демо-сцена |
| `R` | Перезагрузить текущую сцену |
| `P` | Пауза |
| `N` | Один физический шаг (при паузе) |
| `Esc` | Выход |
В левом верхнем углу выводится время физического шага (ms/frame).

Δt = 1/60 с. Снаряд проходит ~33 px за шаг — больше толщины стены, поэтому
геометрическое пересечение не регистрируется и объект «телепортируется»

## Сравнение подходов
| Подход | Устойчивость | Детерминированность | Быстрые объекты | ms/frame |
|---|---|---|---|---|
| Discrete | Высокая при базовых скоростях | Строгая (фиксированный шаг) | Туннелирование при 2000 px/s | 0.00374 |
| CCD | Высокая, требует защиты от «слипания» | Строгая (математическое предсказание) | Корректный отскок, туннелирование устранено | 0.00536 |
| Multi-rate | Средняя | Зависит от порядка sub-stepping | Корректный отскок за счёт микро-шагов | 0.00432 |
**Ограничения CCD:** высокая вычислительная сложность, чувствительность
к ошибкам округления и пограничным случаям (коллизии в нулевом времени —
решаются микро-сдвигом вдоль нормали), сложность синхронного пересчёта при
одновременном столкновении нескольких объектов.
**Ограничения Multi-rate:** темпоральная рассинхронизация — обычные объекты
интегрируются на полный шаг вперёд, поэтому быстрые снаряды на микро-шагах
взаимодействуют с объектами «из будущего»; импульс, переданный обычному
объекту, отразится на его координатах только в следующем глобальном кадре.
